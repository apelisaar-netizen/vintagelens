# Vintagelens / Fookus

A responsive, static photo gallery for exploring lens sample images. The interface is in Estonian and links every photo to its Flickr source.

## Run locally

Open `index.html` in a browser, or serve this directory with any static HTTP server. There are no build steps or package dependencies.

## Sources

Sample photos are embedded from Flickr and link to their original photo or album pages. Lens details are shown when the photographer's description or album identifies the lens.
